# Retail Demand Forecasting & Inventory Optimization

## Project Setup Workflow

1. Clone GitHub Repository
2. Open Project in VS Code
3. Create Python Virtual Environment
4. Verify Python and pip
5. Install Required Packages
6. Create Project Directories
7. Download M5 Dataset
8. Store Dataset in data/raw
9. Verify Dataset Files
10. Load CSV Files using Pandas
11. Check Data Structure and Quality
12. Proceed to BigQuery / ETL

### Week 1 Objective

Set up the local development environment and verify that the M5 retail dataset can be loaded successfully for further analysis and ETL processing.
